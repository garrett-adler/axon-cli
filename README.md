# axon-cli

## Install

```bash
curl -fsSL https://raw.githubusercontent.com/YOUR_USER/axon-cli/main/install.sh | bash
```

Or download and inspect first:
```bash
curl -fsSL https://raw.githubusercontent.com/YOUR_USER/axon-cli/main/install.sh -o install.sh
less install.sh   # review
bash install.sh
```
